# Members of Control that WindowBase/Form do not have.
#
# A Form is not a Control here (Form : WindowBase : Component), so nothing on Control is
# inherited by the window side -- it is all written twice, and anything written once is a
# hole a ported application falls into. This file pins the known holes so a new one cannot
# be added silently; see ControlWindowParityTests.
#
# Methods are Name/argCount; properties and events are just Name.
#
# TRIAGED 2026-08-19. The entries below are grouped by whether they should ever be closed, so the
# list can be worked through instead of stared at. "N/A" groups are the answer, not a backlog: a
# top-level window has no parent to dock against and no Win32 handle to recreate. "WORTH CLOSING"
# groups are the actual backlog, ordered roughly by how likely ported code is to hit them.
#
# 25 entries came off this list in the same pass: the Control EVENTS a WinForms Form inherits
# (MouseClick, BackColorChanged, ControlAdded, PreviewKeyDown and friends) now forward from
# WindowBase to the root ControlAdapter, which is the window's client surface.
#
# Regenerate with MAJORSILENCE_WRITE_CONTROL_WINDOW_BASELINE=1 -- but note that regenerating
# FLATTENS this grouping back to a bare list and loses the triage. Prefer editing by hand; only
# regenerate when a genuinely new gap has to be captured, and re-apply the grouping afterwards.
